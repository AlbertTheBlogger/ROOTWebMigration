# 第一轮推进记录：逆向样本与结算基础

记录日期：2026-11-09。用户要求在本轮节点暂停，完成文档交接。

## 本轮完成

### 1. 可重复的只读研究工具

- `tools/research_baseline.py`：读取 Addressables catalog、link.xml、IL2CPP v29 元数据，校验区段边界、表长度、Token、方法归属和参数；生成类型索引、常量证据及内容线索。
- `tools/research_assets.py`：使用 UnityPy 解析选定资源，导出研究 JSON 与中英文本地化。
- `tools/research_native.py`：静态解析 PE 节与 codegen module，定位少量目标函数；使用 Capstone 导出反汇编，不加载或运行 DLL。
- `tools/research_map.py`：对特定已校验指纹的秋季地图构造函数做受限符号扫描，提取地图常量；变化或无法解析时拒绝继续。
- `tools/research_samples.py`：整理卡牌、地图和流程证据样本、生成地图示意 SVG、校验数据并记录 Python 依赖版本。
- `tools/research_inspect.py`：输出有限的类型和资源摘要，方便后续定位。

原安装包没有被修改或启动。原版资源没有上传服务器。

## 环境与失败记录

- 系统默认 `python` 为 MinGW Python 3.14，且没有 pip；本轮改用已安装的 CPython 3.12 创建 `research/.venv`。
- UnityPy 1.25.4、Capstone 5.0.6 安装在独立研究环境中，完整依赖见 `research/requirements.lock.txt`。
- 官方 PyPI 下载依赖超时，改用清华 PyPI 镜像完成安装。
- 原生方法初始映射失败：代码错误地仅将 `.text` 视为可执行代码；实际 DLL 包含 `il2cpp` 可执行节。已改为读取 PE 执行属性，并增加相应测试。旧诊断文件保留用于追溯，以 native-index.json 为当前成功结果。
- Cpp2IL / Il2CppDumper / AssetRipper 本轮未安装或实际运行；仅参照 LibCpp2IL 的公开结构定义编写受限解析器。不要把候选工具写成已使用工具。
