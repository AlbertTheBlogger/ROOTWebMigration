# 注册延迟排查与反馈修复

用户报告注册点击后约十秒没有反馈，刷新后显示已登录。

实测服务器本机登录验证 66–68ms，密码 scrypt 单次约 72ms。公网健康接口约 41ms，登录失败请求 101–108ms。公网成功注册请求 101ms，后续房间列表 40ms，从点击到大厅 242ms。测试时服务器负载接近零，数据库 quick_check 为 ok。

十秒延迟未复现，当前证据不足以确定当时的网络或浏览器根因。代码确认注册提交没有可见等待状态，且成功后的页面切换依赖房间列表返回。

前端已增加提交按钮禁用、转圈、状态提示与三秒后的慢请求提示。认证成功立即显示大厅，随后加载房间列表。错误后恢复按钮并显示错误。未降低密码哈希强度。

回归在临时本地数据库中分别延迟注册与房间列表 1.8 秒，验证加载提示、按钮禁用、房间列表完成前已进入大厅。完整双浏览器流程和 49 项 Node 测试通过。

公网修复已发布，旧前端保存在 `/opt/woodland-auth-backup-20261109/`。只更新 app.js 和 styles.css，服务使用每次读取静态资源的方式，无需重启。两个诊断专用注册账号均已清理。

研究记录位于 `audit/browser-acceptance/registration-latency.json`。公网加载反馈截图位于 `audit/browser-acceptance/public-auth-loading.png`。若用户仍出现长延迟，下一步需要用户浏览器中注册与房间请求的 Network 耗时，以定位等待所在阶段。
